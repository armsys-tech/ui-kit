Armsys UI

One framework-independent visual language for Armsys websites, documentation, dashboards, admin panels, embedded tools and Electron apps. Plain HTML, CSS custom properties and ~20 KB of gzipped vanilla JavaScript.

No build step Scoped to .aui Dark-first + full light theme Vue · Electron · Razor · Blade · Go

Install

Use the CDN for plain pages, or npm for Vue / Vite / Electron projects. Pin the version in production.

<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@armsys-tech/ui@2.0.0/dist/armsys-ui.min.css">
<script src="https://cdn.jsdelivr.net/npm/@armsys-tech/ui@2.0.0/dist/armsys-ui.min.js" defer></script>

<body class="aui">
  <button class="aui-btn aui-btn--primary">Deploy</button>
</body>

Control sizes, radius & density

Buttons, inputs, selects and segmented controls share --aui-control-h-* (24 · 30 · 36 · 42 · 48), so they always line up in toolbars and forms. .aui--dense and .aui--comfortable shift the whole scale.

Frame & layout

Version 2 has one frame. The website, documentation, pricing and data pages all use the same .aui-site-header, the same .aui-container width (--aui-frame: 1440px) and the same 64 px header height (--aui-header-h). The docs sidebar's link text lines up with the header logo, so moving from the marketing page to the docs keeps the same layout.

    Dropdown menus

At ≤640 px they open as a bottom sheet; opt out with data-aui-sheet="false".

    Modal, bottom sheet, drawer

    All overlays are native <dialog> elements opened with data-aui-modal-open="#id" or ArmsysUI.openModal('#id'). They animate in and out, lock page scroll, close on Escape and backdrop click (data-aui-static prevents that). On phones every modal becomes a bottom sheet with a drag handle — swipe down to dismiss, like Flutter's showModalBottomSheet.

    Dialog API

    Promise-based replacements for window.confirm/prompt/alert, styled and sheet-aware. For links and buttons, data-aui-confirm="Title" asks before the click goes through.

    Command palette

    A <dialog class="aui-command" data-aui-command> opens with ⌘K / CtrlK or any data-aui-command-open trigger. Items are filtered by text and data-keywords; arrows + Enter run them.

    Code

    Write plain <pre><code class="language-js">. Armsys UI lazy-loads highlight.js from cdnjs on first use and paints it with an Atom One Dark palette mapped to --aui-code-* tokens (also in the light theme). Languages not in the core bundle (e.g. dart) are fetched on demand. Disable with window.ArmsysUIConfig = { highlight: false }.

    Vue · Electron · .NET · Laravel

    There is nothing to wrap: Armsys UI is classes + data attributes. A MutationObserver initialises markup that frameworks render later (v-if, router views, Blazor/HTMX swaps), so you import it once. Recipes live in integrations/.

    ArmsysUI.toast({ title: 'Deleted', variant: 'success' });
  }
};
</script>

    AI usage

    Armsys UI ships a machine-readable catalogue so an assistant can build a complete admin panel or docs site without reading the CSS. Point the model at llms-full.txt (everything in one file) or start from ai/index.json.

    One-file context

    llms-full.txt — rules, tokens, every component with markup, JS API and page recipes.

    Structured

    ai/components.json · ai/patterns.json · ai/tokens.json · ai/javascript.json · ai/recipes/*.md

    prompt.txt
    Build an admin panel for managing VPN servers using Armsys UI 2.
Read https://cdn.jsdelivr.net/npm/@armsys-tech/ui@2/llms-full.txt first and follow its rules:
use only aui-* classes and --aui-* tokens, the .aui-app sidebar shell, data-aui-* behaviours,
ArmsysUI.confirm() for destructive actions and toasts for results. No other UI framework.
