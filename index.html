Armsys UI

One framework-independent visual language for Armsys websites, documentation, dashboards, admin panels, embedded tools, messengers and Electron desktop apps. Plain HTML, CSS custom properties and ~20 KB of gzipped vanilla JavaScript.

No build step Scoped to .aui Dark-first + full light theme Vue · Electron · Razor · Blade · Go

Install

Use the CDN for plain pages, or npm for Vue / Vite / Electron projects. Pin the version in production.

<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@armsys-tech/ui@3.0.0/dist/armsys-ui.min.css">
<script src="https://cdn.jsdelivr.net/npm/@armsys-tech/ui@3.0.0/dist/armsys-ui.min.js" defer></script>

<body class="aui">

</body>

Control sizes, radius & density

Buttons, inputs, selects and segmented controls share --aui-control-h-* (24 · 30 · 36 · 42 · 48), so they always line up in toolbars and forms. .aui--dense and .aui--comfortable shift the whole scale.

Buttons

.aui-btn + one variant + optional size and shape. Variants only set private properties, so every combination stays consistent.

Variants

Use one primary per view. Accent is for brand moments and selected states; danger for destructive confirmations.

Semantic tones

Solid: aui-btn--success|danger|warning|info. Combine a tone with --soft, --outline or --ghost for quieter actions.

Sizes

Icons, counts, shortcuts

States

.is-loading keeps the label and adds a spinner. aria-pressed="true" / .is-active for toggles. disabled on buttons, aria-disabled on links.

Groups, split & toggle groups

Over media: inverse & glass

aui-btn--inverse and aui-btn--glass keep fixed colours in both themes — for image viewers, video players and the call stage. Combine glass with --danger for hang-up.

Toggles, icon swap & stacked

aui-btn--toggle + aria-pressed flips automatically on click and takes the tone when pressed. Put two icons inside with aui-btn-on / aui-btn-off to swap them (mic ↔ mic-off). aui-btn--stack places a short label under the icon; aui-btn--round is a circular icon button; aui-btn--dashed marks "add new" placeholders; aui-btn-badge is a corner count.

    Date picker & calendar

    Add data-aui-datepicker to any text input: focusing it opens a floating calendar (flip/shift aware, Escape closes, arrows move between days). Native type="date|time" inputs stay native — use the picker when you need one look across platforms (Electron, Windows WebView2).

    Input picker

    min/max, data-aui-format="dd.mm.yyyy" (default ISO), data-aui-week-start="0|1", data-aui-locale="tr", data-marked="2026-11-05 2026-11-12". Fires aui:date on the calendar and change on the input.

    Inline calendar

    <div data-aui-calendar data-value="…"> renders in place. Sizes aui-calendar--sm|lg, aui-calendar--block stretches to the container; click the title to jump by month and year. ArmsysUI.setDate(el, '2026-12-24') sets it from code.

    Dropdown menus

    Wrap a trigger and a .aui-menu in [data-aui-dropdown]. Menus are positioned with flip/shift so they never leave the viewport (even inside scrolling tables), support arrow keys, Home/End, typeahead, submenus, checkable items and search. At ≤640 px they open as a bottom sheet; opt out with data-aui-sheet="false".

    Desktop workbench

    The parts an Electron / Tauri application is built from, on top of .aui-desktop + .aui-titlebar: menubar, tool strip, activity rail, editor tab strip, tree view, resizable panels, panel groups and a property grid. See the workbench example for the full shell.

    Menubar & tool strip

    .aui-menubar[data-aui-menubar] holds ordinary dropdowns: while one is open, hovering or ←/→ switches menus like a native menubar. .aui-toolstrip is a 40px row of 28px buttons with .aui-toolstrip-sep separators. Both sit inside the title bar or directly under it.

    Zoom

    Tab strip

    Editor / browser tabs on top of data-aui-tabs. Tabs are <div role="tab" data-aui-tab> so a close button can sit inside; data-aui-tab-close closes (cancelable aui:tab-close, middle-click and Del work too), data-aui-tab-add fires aui:tab-add. States: is-modified, is-pinned. Variants --chrome (browser) and --pills.
